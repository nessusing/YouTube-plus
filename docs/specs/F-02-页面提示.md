# F-02 页面提示

**what**：各功能共用的页面提示条，仿 YouTube 官方的提示样式。

**验收标准**
- F-02-AC1 只在出事的那个标签页弹出。（§46）
- F-02-AC2 提示条只能横向拖动，拖到的位置在所有标签页共用。（§46）
- F-02-AC3 提示条会避开迷你播放器和迷你播放器最小化后的横条。（§46）
- F-02-AC4 新提示的文字跟正在显示的某一条相同时不叠加，只把那一条重新计时。（§46）
- F-02-AC5 设置页「通知」标签可以调位置、同时显示的条数、显示时长，并能预览。（§46）
- F-02-AC6 全屏时提示条显示在全屏画面里；控件栏显示时挪到控件栏上面，不压进度条，控件栏隐藏后回到底部。

**相关决策**：D-003、D-023

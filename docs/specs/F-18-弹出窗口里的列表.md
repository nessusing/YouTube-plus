# F-18 弹出窗口里的列表

**what**：弹出到桌面的播放器（F-11）里也能看到、点列表，不用回到标签页。F-11 的二期。

**验收标准**
- F-18-AC1 在播列表时，弹出窗口里显示这个列表；点其中一条就换到那条视频，画面留在弹出窗口里。
- F-18-AC2 列表高度跟着窗口大小变（窗口大小由用户拖）；窗口矮时可以把列表收起。

**待定（开工前决定）**：显示哪些列表？
- 选项 A：只在 F-05 接管、而且在放选中的那个列表时显示。
- 选项 B：任何正在放的列表都显示，包括 YouTube 自带队列和别人的列表。

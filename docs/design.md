# YouTube+ 设计文档

> 个人自用的 Chrome 扩展（MV3），YouTube 工具合集。本文只记**已经做完**的功能：做什么、几条故意的规则（看着像 bug、其实是这样定的）、不做什么。规格、参数、做法和实测结论在代码和代码注释里；完整的讨论和实测过程在 git 历史（`cc6a7bb` 及之前的 `docs/design.md` 最详细）。没做完的在 [plans.md](plans.md)。
> 章节号固定（代码注释引用 §n），本文没列出的编号都是空号，不再使用。新章节从 §53 往下编。

**四个功能**：TL;DR（第二部分）、队列（第三部分）、播放器（第四部分）、评论弹幕（第五部分）。完成日期和还没测的部分见文末「完成记录」。

# 第一部分　共用

## 2. 原则

- 自用，但按能上架的标准写；零成本（用浏览器已登录的账号，不用 API key / OAuth）；每个功能单独开关、互相隔离；WXT + TypeScript + 原生 DOM / Shadow DOM。
- **贴合官网**：能从官网拿到的（账号、播放列表、语言等）直接用，不另存、不让用户再设；界面和交互仿官网。
- **开发和测试时静音**：优先在浏览器层面（e2e `--mute-audio`；手动给标签页静音），不改播放器自己的音量。
- 图标 `docs/icon-drafts/d.svg`；红色播放键取自 YouTube 商标，**上架前必须改掉**（plans.md P1）。工具栏图标只跟总开关走（开彩色、关灰色），跟当前网站无关；点图标打开设置页。

## 3. 设置页

- 首次安装打开「诊断」并跑自检；链接指定了标签就开那个；其余总是开「通用」，不记上次的标签。
- **扩展语言 = YouTube 的界面语言**，没有语言选项（`zh*` → 中文，其他 → English；没开过 YouTube 时按浏览器语言）。**待手测**，见 plans.md P23。

## 4. 日志

全扩展共用一份环形缓冲；永不上传，不记 cookie 和认证头。

### 4.1 存储用量

「存储」标签显示各类用量，可调上限、可清空。

## 5. 自检

结果：通过、失败、跳过，以及「注意」（黄色：能用，但缺了用户该知道的东西，不算失败）。

## 46. 页面提示

各功能共用的提示条（`src/core/notify.ts`），仿官方。只在出事的标签页弹。只能横向拖，位置在所有标签页共用；会避开迷你播放器和横条。文字跟显示中的某条相同时不叠加，只重新计时。设置页「通知」标签可调位置、条数、时长、预览。

# 第二部分　TL;DR

后台调用免费的 Gemini 网页版（逆向内部接口）读视频生成要点；点缩略图上的图标看。

## 7. 目标与非目标

不做：Shorts、直播中、预告和首映；自抓字幕；读不到字幕时的降级总结；官方 API（只留接口，plans.md P3）。

## 8. 关键决定一览

所有带缩略图的位置都生效；3–7 条要点 + 标题一致性判断；用普通对话（临时对话用不了 YouTube 应用），生成完立即删除；接受封号风险。需要用户开 Gemini 应用活动记录并启用 YouTube 应用；没字幕的视频读不了。

## 9. 架构

content script（缩略图、图标、tooltip）↔ service worker（任务队列、缓存、Gemini 客户端）。协议细节只在 `GeminiWebClient` 和 `protocol.ts` 里。

### 9.1 Provider 接口

`SummaryProvider`；以后加官方 API 只需新增一个实现（plans.md P3）。

## 10. Gemini 网页版协议

两条都是内部接口，变了自检会报 `protocol`；都失效时见 plans.md P3。参考：Sophomoresty/gemini-web2api、ntthanh2603/gemini-web-to-api、HanaokaYuzu/Gemini-API（AGPL，只参考协议）、zexadev/gemini-web2api-go。

### 10.1 抓取 token
每次请求前从 `/u/N/app` 页面取（plans.md P2 打算缓存）；拿不到 = 未登录或第三方 cookie 被屏蔽。

### 10.2 发起生成
`processSession`（§10.8）优先，`StreamGenerate`（旧接口）后备。报 `protocol` / `auth` 时换另一条；额度、封锁、临时错误不换（按账号算）。不轮换 cookie。

### 10.4 删除对话
失败的进 `PendingDeletes` 重试。

### 10.8 `processSession`
网页前端 2026-10 起用的 WebChannel 协议，格式见 `protocol.ts`、`client.ts` 的 `viaSession`。**坑**：不带 `SAPISIDHASH` 不报错，而是当匿名用户回答；哈希失效目前检测不到。

## 11. Prompt 与输出格式

严格输出 JSON，读不到内容时说 `no_transcript`、禁止编造；解析失败时把原文当 markdown 显示。**要点用视频自己的语言**，跟扩展语言无关（**待手测**，plans.md P23）。

## 45. 不受 Gemini 个性化设置影响

账号里的个性化（指令、人设、保存的信息）也会作用到扩展的请求上。prompt 开头声明这是程序发的请求、个性化一概不适用，结尾再强调只回 JSON。还出问题时的兜底（拆成单个重试）跟 plans.md P16 一起做。

## 12. 预生成、任务队列与限流

全局一个串行队列，一次最多 5 个视频；点击 > 可见 > 其余；只在 YouTube 标签页在前台时预生成；有每小时 / 每天上限（手动点击不受暂停影响但计数）和熔断；未登录全部停。

## 13. 缓存

按 videoId 缓存，不分扩展语言（内容是视频的语言）；成功永久（LRU）；`unreadable` 24 小时；错误不缓存。

## 14. UI

### 14.1 缩略图上的图标
时长标签上方、常驻，位置按时长标签量（不同列表里位置不同，不写死）；按状态变色。层级低于顶栏和迷你播放器。

### 14.2 Tooltip
标题一致性判断 + 要点；重新生成、复制。

### 14.3 识别缩略图
选择器集中在 `selectors.ts`；排除 Shorts、直播、预告。

## 15. 设置与自检

自检：拿 token、跑一次真实总结（显示走的哪条通道）、删除对话。

### 15.1 登录 Gemini 的引导
未登录时什么都不跑，图标显示「需要登录」，tooltip 给「登录 Gemini」「我已登录」；Gemini / Google 账号页加载完和每 10 分钟自动重测。

# 第三部分　队列

设置里二选一：YouTube 自带的队列（扩展完全不管），或用一个播放列表当队列（接管「加入队列」，顶栏一键播放，看完自动删）。参考：Trinovantes/userscript-youtube-playlist-organizer、YouTube.js `PlaylistManager.ts`、PlaylistPlus。

## 21. 背景

播放列表的读写、菜单结构、认证等实测结论都在 `queue/innertube.ts`、`main-world.ts`、`page-menus.ts`、`core.ts` 的注释里。下面几条是代码注释引用的结论。

### 21.2 「加入队列」是怎么触发的
所有入口都冒泡同一个 `yt-action`，在 capture 阶段能完全拦下。例外：标签页已有官方队列且迷你播放器开着时，点缩略图直接写官方队列，拦不到。

### 21.3 改菜单文字
按图标或命令识别菜单项，不看文字。菜单 DOM 跨页面复用，每次打开都要改、关掉模式要改回。

### 21.4 播放列表的读写和播放
服务器不去重（`DEDUPE_OPTION_SKIP` 无效），写后几秒内可能读到旧数据，新建的列表最初一两秒读起来不存在；所以加入前先读、读到「不存在」要复查。正在播的列表被删条目后官方自动播放会出错，所以由扩展自己切下一条。

### 21.5 认证和身份
品牌频道必须带 `X-Goog-PageId`，不带会悄悄按主频道执行。身份用 `DATASYNC_ID`。

## 22. 关键决定一览

播放列表模式接管所有走 `yt-action` 的入口；「播放完后删除」默认勾选；设置按身份（频道）分开存；没选列表或无权编辑时不接管；切换模式不迁移数据。

## 23. 架构

写操作都在 MAIN world；isolated 一侧管界面；设置页通过最近用过的 YouTube 标签页读写；纯逻辑不碰 DOM、依赖注入，便于单测。

## 24. 播放列表模式

### 24.1 什么时候接管
队列功能开、当前身份选了播放列表模式、已登录、选了列表、列表可编辑。不可编辑时提示但不清空选择。

### 24.2 加入
先去重再加；在看列表外的视频时把列表挂到当前播放上。失败只提示和写日志，不重试。

### 24.3 改文字
菜单和缩略图悬停按钮都改成「加入 <列表名>」，不接管时改回。

### 24.4 播放和看完删除
- 只在播这个列表时算看完：播完，或剩不到 10 秒时切走 / 关标签页。勾选删除时扩展跳到下一条再删；不勾选交给官方自动播放。最后一条删掉后不再管，照 YouTube 自己的自动播放走。
- 点顶栏按钮：正在放这个列表时接着放当前这条（不从第 1 条开始）。
- 迷你播放器里放完留在迷你播放器，不展开成观看页。
- 刚看完删掉的视频不会被当成「列表外的视频」放回面板第一位。

### 24.5 选列表、新建、列表被删
「新建…」默认名 `YouTube +`、私密。列表确认不存在时清空选择并提示去设置；复查期间用户换了列表就不清。

### 24.6 切换模式
已开的标签页立刻按新模式走，提示刷新后完全生效。切回自带队列后，原生「加入队列」会直接加进正在播的列表，是原生行为，不拦。

### 24.7 身份
按频道分开，存 `chrome.storage.sync`（模式、列表、看完删除）。

### 24.8 界面跟列表保持同步
监听页面自己的列表修改，合并后重读，数字和面板跟上；扩展删除后面板当场去掉那几行，不等重读；删空时面板显示「1 / 0」，跟官方一样。

## 25. 清空全部与移除已看完

见 §47。

## 47. 清空全部与移除已看完（官方 ⋮ 菜单）

- 加在官方 ⋮ 菜单最下面：列表页（能编辑的列表，两种模式都有）；观看页和迷你播放器的列表面板（只在接管、且面板是选中的列表时）。找不到官方 ⋮ 就没有入口，不自己补按钮。
- **点了直接删，不确认、不能撤销、不存快照**（故意的）。「已看完」= 观看进度 ≥ 90 %。
- **正在播的视频被删**（这里或 §48）照常播完，再接着播原来排在它后面还留着的；没有就交给 YouTube 的自动播放。

## 48. 拖出列表面板删除

在观看页、迷你播放器的列表面板里，把一条拖到面板外松开就删掉（拖出时那行变红「松开即删除」）。只在接管且面板是选中的列表时；列表页没有。松开即删，不弹提示、不能撤销；失败时那行回原位并提示。原来想做的「列表页多选后删除」不做了。

## 26. 失败处理

失败只提示和写日志、不重试；认不出菜单或命令结构时不拦、退回原生；读不到任何可编辑列表视为协议错误，停止接管并在设置页显示。

## 27. 设置与自检

队列标签显示正在设置哪个频道（头像 + 名字）、模式（默认自带队列）、列表、播放完后删除。自检：页面正常、选中列表可编辑、拦截已装上。

## 28. 实现细节

跳下一条用站内导航，1.5 秒内页面没开始导航就整页跳转。

### 28.1 关标签页时的删除
剩不到 10 秒时关标签页：删除请求提前签好，`pagehide` 时用 `keepalive` 发出。

## 29. 测试

- L1 纯函数、L2 controller 集成（内存里的假 YouTube）：`npm test`。L4 在真实 YouTube 上（Playwright，`tests/e2e/`）：先 `npm run e2e:login`，再 `npm run test:e2e`；`npm run test:all` 全跑。
- L4 只碰名字以 `YouTube+ e2e` 开头的列表，用跨运行保留的小池（YouTube 限制每天新建列表数）。
- 测试发现的问题 F1–F17 见 git 历史里的 `docs/queue-test-findings.md`；还在观察的 F12 在 plans.md P11。

# 第四部分　播放器

迷你播放器和大播放器是同一个 `#movie_player`。子开关都在「设置 → 播放器」，除循环按钮外默认开。

## 35. 迷你播放器

### 35.1 控件
悬停时显示官方控件栏（音量、进度条、时间、齿轮）。不补上一个 / 下一个（YouTube 2026-11 改版自己去掉的）。

### 35.2 拖动与吸附
只从视频区域开始拖；松手离边近就吸边、在角落吸角，否则停在原地。

### 35.3 记住位置和大小
所有标签页共用，设置页可重置。

## 36. 观看页

### 36.3 小窗时按 `t` 或点影院模式按钮
回到页面顶端并进入影院模式（§49）。

### 36.4 小窗时点时间戳
只跳时间，不滚动页面。

## 37. 回到顶部按钮

所有页面，滚过 300 px 出现，点了直接跳到顶端。跟迷你播放器重叠时迷你播放器在上（先这样，以后再看）。

## 40.2 单个视频循环

- 控件栏 ▶ 右边一个循环开关（迷你播放器没开控件时在画面正中大 ▶ 右边），默认关。跟右键菜单「循环播放」同一个状态；只对当前视频，换视频 YouTube 自己关。没有快捷键。不做频道页预告片、Shorts、悬停预览、嵌入播放器。
- **跟队列**（接管并播放选中列表时）：循环开着时这个视频不算看完。循环过至少一次后在列表里切到别的视频，就把它当看完删掉；去看列表外的视频、关标签页不删。

## 44. 迷你播放器最小化

迷你播放器 ✕ 左边一个按钮，缩成左下角只显示标题的横条，视频继续播；点横条还原。最小化状态记住（刷新、所有标签页）。迷你播放器只是藏起来、没关，所以队列、拖动都不受影响。

## 49. 观看页往下滚时播放器缩成小窗

往下滚到播放器露出不到一半时缩成右下角的小窗（「回到顶部」左边），滚回来恢复；普通、影院模式都一样，全屏不变。可拖动，位置跟迷你播放器分开记；左上角「展开」回到顶端。替换了原来的置顶和影院模式自动切换。**没测到**：小窗时换视频、广告、全屏进出、直播聊天、窗口缩放。

## 50. 迷你播放器弹出到桌面

- 用 Document PiP 把整个播放器搬到一个置顶的桌面窗口里（Chrome / Edge 116+；不支持时设置项变灰、自检「注意」）。只放画面和控件；列表见 plans.md P25。
- 打开：迷你播放器「展开」右边的按钮，或快捷键（默认 Shift+I，可改，跟 YouTube 自己的快捷键冲突时不让存）。在播放页按快捷键会先缩成迷你播放器再弹出。切走标签页时不自动弹。
- 弹出期间主页面仍是迷你播放器状态（藏起来，左下角横条「在弹出窗口里播放」）；在浏览页点视频、列表下一条都在 PiP 里接着播。PiP 里有完整控件栏和常用按键。
- 收回：快捷键、横条、✕；主页面去播放页、后退到正在播的视频、Esc 关迷你播放器时也收回。
- **全屏**：PiP 窗口里不许全屏，所以全屏 = 收回 → 浏览器窗口全屏 → 播放器盖满整页；退出全屏后回到 PiP。
- **改不了**：标题栏是 Chrome 画的；只能由用户操作打开；同时只有一个 PiP；Wayland 下可能不置顶（没测）。

# 第五部分　评论弹幕

## 51. 评论弹幕

评论在播放时出现在播放器上，默认关。带时间戳的评论在那个时刻出现；其余的用本地算法按热度撒到全片，或由 Gemini 读字幕放到相关时刻。参考 ComVi（CHI 2026，arXiv 2603.26173）。实测脚本和数据在 `scripts/danmaku/`；测试对话留在 Gemini 里：`/app/0db1d17598b5234a`、`/app/faedcf8cdec9d3f1`、`/app/dfae8bc08115018e`、`/app/0f6c3c210f8b6d59`。

### 51.1 范围和开关
- 只在观看页（含 §49 小窗、影院、全屏）显示；迷你播放器、弹出窗口、广告时隐藏。不做：嵌入、music、Shorts、直播和直播回放（按钮变暗）。
- AI 只走 Gemini，不看画面，只靠字幕和评论文字；不内置本地模型。
- 全局开关默认关，关时什么都不跑。控件栏字幕按钮左边一个开关，像字幕按钮一样记住、对所有视频生效。
- 只处理当前观看页的视频，不提前生成；切视频立刻停掉旧的（已发出的 Gemini 请求跑完、照样缓存）。

### 51.2 拉评论
直接调 InnerTube，不滚页面、不碰评论区；不登录也能拉。只拉「热门」的前几百条（不全拿）、只用一级评论。评论一视同仁：不按语言筛，置顶和作者评论不加权。

### 51.3 过滤和热度
带链接、纯表情、太短、重复的不显示也不送 Gemini。热度综合赞数、回复数、新旧。

### 51.4 带时间戳的评论
- 每个时间戳出现一次；真目录（0:00 开头、5 个以上）只在 0:00 显示一次。
- 时刻被占了只往后推（最多 5 秒），**不提前**（免得剧透），推不进就放弃。
- 同一时刻的几条放进同一张卡轮播，最多 3 条。

### 51.5 定位方式
- 设置里选「本地」（默认）或「AI」，切换后马上重排。
- **本地**：评论多的视频每分钟多放几条；按「最常重播」热度分配到各段；同一个视频每次排得一样。带「结尾」「反转」等词的只放最后 20 %。
- **AI**：只信置信度 ≥ 0.9 的时间，其余的只用来填超过 20 秒的空档。Gemini 回来前只显示带时间戳的（没看过的评论可能剧透）。请求排在所有 TL;DR 前面，不受每小时 / 每天上限约束，但受熔断约束。整个视频用不了 AI 时（没字幕、没登录、额度、风控）按设置退回「本地」或「只显示带时间戳的」，不弹提示。

### 51.6 排期
同一时间只显示一条，评论少时不硬凑。显示时长按字数，长评论分屏滚动、不设长度上限。重排时只改还没开始的卡片，已显示过的不重复。

### 51.7 显示（字幕卡）
播放器顶部居中，仿官方字幕：胶囊底，开头 `@handle`，不显示头像和赞数，链接、@提及不能点；一屏两行。避开顶部标题栏和上半部分的字幕。不能拖。烧进画面的字幕测不到。

### 51.8 缓存、日志和自检
按视频缓存 7 天（单独上限）；过期后重拉评论，Gemini 的判断保留。Gemini 的原始回答全记进日志。自检只试拉评论，不试 Gemini。

### 51.9 设置页
「评论弹幕」标签：风格、定位方式、AI 用不了时的行为、调试、可编辑的提示词、七组参数（每组可恢复默认）、假播放器预览。开发期间放出的参数哪些留给普通用户，以后再定。

## 52. 弹幕风格

三种，设置里单选、马上生效：**字幕卡**（§51.7，默认）、**飞过**（单行从右飞到左，条目和时间同字幕卡，可重叠，太长的不飞）、**侧栏**（播放器右边的评论列表，像评论区：头像、赞数、嵌套回复，滚到底加载更多；只读；不筛选、不定位、不缓存）。主题和动画见 plans.md P29。

### 52.1 胶囊底
两行的卡片也是一整个胶囊。

### 52.4 设置页和测试
字幕卡和飞过有预览，侧栏没有。没有 L4。

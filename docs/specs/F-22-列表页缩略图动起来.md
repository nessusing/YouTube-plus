# F-22 列表页缩略图同时动起来

**what**：首页、搜索、频道页等列表页上，看得见的视频缩略图同时动起来，不用一个个悬停，方便挑视频。只是动图，没有声音，不是真的播放。

**验收标准**
- F-22-AC1 列表页上看得见的卡片同时显示动图，不开播放器、没有声音；拿不到动图的卡片保持静止。
- F-22-AC2 只处理看得见的卡片，滚出视野就换回静态图。
- F-22-AC3 设置里有开关，默认关。
- F-22-AC4 不碰 YouTube 自己的悬停预览；两者同时存在时以悬停预览为准。

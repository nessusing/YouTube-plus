# F-19 弹幕里显示头像

**what**：字幕卡和飞过两种风格里，`@handle` 前面显示评论者的头像，像评论区一样（侧栏本来就有头像）。

**验收标准**
- F-19-AC1 字幕卡和飞过里，`@handle` 前显示圆形头像，高度跟一行字一样；头像加载失败或没有头像地址就不显示，不留空位。
- F-19-AC2 估算行数和显示时长时把头像的宽度算进去（字幕卡的时长、飞过的「太长不飞」和车道安排）。
- F-19-AC3 设置页预览的示例卡片也带头像。
- F-19-AC4 弹幕缓存存下头像地址；升级前缓存的评论没有头像，照常显示，过期重拉后才有（D-025）。缓存默认上限 3 MB（D-025）。

**相关决策**：D-025；F-12-AC12、F-12-AC15 跟着改。F-20（主题和动画）以后单独做。

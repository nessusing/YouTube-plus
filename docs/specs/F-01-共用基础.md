# F-01 共用基础

**what**：各功能共用的底座：总开关和每个功能的开关、工具栏图标、设置页、日志、存储用量、自检。

**验收标准**
- F-01-AC1 每个功能有单独的开关，互相隔离；总开关关掉时什么都不跑（⚠️ 未确认：后半句是推断）。（§2）
- F-01-AC2 工具栏图标只跟总开关走：开时彩色、关时灰色，跟当前在哪个网站无关；点图标打开设置页。（§2）
- F-01-AC3 首次安装打开设置页的「诊断」标签并跑一次自检；链接里指定了标签就开那个；其余情况总是开「通用」，不记上次的标签。（§3）
- F-01-AC4 全扩展共用一份环形日志；永不上传，不记 cookie 和认证头。（§4）
- F-01-AC5 设置页「存储」标签显示各类数据的用量，可调上限、可清空。（§4.1）
- F-01-AC6 自检结果分四种：通过、失败、跳过、注意。「注意」（黄色）= 能用但缺了用户该知道的东西，不算失败。（§5）

# F-05 队列（播放列表当队列）

**what**：设置里二选一：用 YouTube 自带的队列（扩展完全不管），或用一个自己的播放列表当队列——扩展接管「加入队列」把视频加进这个列表、顶栏一个按钮一键播放、看完自动从列表删掉。播放列表存在 YouTube 账号里，所以跨标签页、跨设备都在。

**验收标准**

设置和身份
- F-05-AC1 模式、选中的列表、「播放完后删除」按频道（身份）分开保存，跟着 Chrome 同步；默认是自带队列；「播放完后删除」默认勾选；切换模式不迁移数据。（§22、§24.7、§27）
- F-05-AC2 设置页队列标签显示正在设置哪个频道（头像 + 名字）、模式、列表、播放完后删除；「新建…」建一个私密列表，默认名 `YouTube +`。（§24.5、§27）
- F-05-AC3 自检：页面正常、选中的列表可编辑、拦截已装上。（§27）

接管
- F-05-AC4 只在这些条件都满足时接管：队列功能开、当前身份选了播放列表模式、已登录、选了列表、列表可编辑。列表不可编辑时提示，但不清空选择。（§24.1）
- F-05-AC5 接管所有入口的「加入队列」（菜单、缩略图悬停按钮等），视频加进选中的列表。例外：标签页里已有官方队列且迷你播放器开着时，点缩略图会直接进官方队列，拦不到。（§21.2、§22）
- F-05-AC6 加入前先去重；在看列表外的视频时把列表挂到当前播放上。（§24.2）
- F-05-AC7 接管时菜单项和缩略图悬停按钮的文字改成「加入 <列表名>」，不接管时改回。（§21.3、§24.3）
- F-05-AC8 切换模式后，已开的标签页立刻按新模式走，并提示刷新后完全生效。切回自带队列后，原生「加入队列」直接加进正在播的列表是原生行为，不拦。（§24.6）

播放和看完删除
- F-05-AC9 顶栏有一个播放按钮；正在放这个列表时点它接着放当前这条，否则从列表开头放。（§24.4）
- F-05-AC10 只在播这个列表时算「看完」：播完，或剩不到 10 秒时切走 / 关标签页。（§24.4、§28.1）
- F-05-AC11 勾选「播放完后删除」时，看完由扩展跳到下一条再删；不勾选时交给 YouTube 自己的自动播放、不删。最后一条删掉后不再管，照 YouTube 的自动播放走。（§24.4）
- F-05-AC12 在迷你播放器里放完一条后留在迷你播放器里，不展开成观看页；刚看完删掉的视频不会被当成「列表外的视频」放回面板第一位。（§24.4）

同步和出错
- F-05-AC13 顶栏数字和列表面板跟列表的实际内容同步：页面自己（或别的标签页）改了列表后跟上；扩展删除后面板当场去掉那几行；删空时面板显示「1 / 0」，跟官方一样。（§24.8）
- F-05-AC14 选中的列表确认不存在时清空选择并提示去设置；复查期间用户换了列表就不清。（§24.5）
- F-05-AC15 失败只提示和写日志、不重试；认不出菜单或命令结构时不拦、退回原生行为；读不到任何可编辑列表时视为协议错误，停止接管并在设置页显示。（§26）

**假设**：队列不会很长，不需要很细致的管理（D-010）。

**不做**：插到下一个播放（F-16，暂停）。

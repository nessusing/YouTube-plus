# F-19 弹幕里显示头像

**what**：在弹幕的 `@handle` 前面加上评论者的头像（现在不显示头像，F-12-AC12）。

**验收标准**
- F-19-AC1 `@handle` 前显示圆形头像，高度跟一行字一样；头像加载失败就不显示，不留空位。
- F-19-AC2 估算行数和显示时长时把头像的宽度算进去。
- F-19-AC3 设置页预览的示例卡片也带头像。

**开工时再定**：缓存里的旧评论没有头像——是让它们 7 天内不带头像显示，还是给缓存加版本号让旧缓存作废；每条评论多存一个地址后，2 MB 的缓存上限够不够。
**相关**：跟 F-20（弹幕主题和动画）一起考虑；F-12-AC12 要跟着改。

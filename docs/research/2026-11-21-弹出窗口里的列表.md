# 弹出窗口里的列表：怎么做（2026-11-21）

F-18 的方案材料。PiP 窗口是一个完整的空白网页，什么都能放。

- **不搬 YouTube 的列表面板**（`ytd-playlist-panel-renderer`）：它的点击、换视频、删除、拖动排序都靠事件冒泡到主页面的 `ytd-app`，搬过去就传不过去了；样式要整套复制；YouTube 重绘时还会跟我们抢。
- **在 PiP 窗口里自己画列表**，数据用队列现有的那套；点某一条时交给主页面去换视频。原型里在 PiP 里调播放器的 `playVideoAt(i)` 换到列表第 i 条，画面留在 PiP 里，可行。
- 窗口大小由用户拖，列表跟着窗口高度变，窗口矮时可以收起。

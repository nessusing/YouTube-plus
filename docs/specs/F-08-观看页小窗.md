# F-08 观看页往下滚时播放器缩成小窗

**what**：在观看页往下滚（看评论等）时，播放器缩成右下角的小窗继续播；滚回来恢复。

**验收标准**
- F-08-AC1 往下滚到播放器露出不到一半时，缩成右下角的小窗（在「回到顶部」按钮左边）；滚回来恢复。普通模式、影院模式都一样（影院模式保持影院模式）；全屏不变。（§49）
- F-08-AC2 小窗可以拖动，拖到的位置会记住，跟迷你播放器的位置分开记。（§49）
- F-08-AC3 小窗左上角的「展开」回到页面顶端。（§49）
- F-08-AC4 小窗时按 `t` 或点影院模式按钮：回到页面顶端并进入影院模式。（§36.3）
- F-08-AC5 小窗时点评论里的时间戳只跳时间，不滚动页面。（§36.4）

**还没测到的情况**：小窗时换视频、全屏进出、直播聊天、窗口缩放（TASKS）；广告暂不测（D-024）。

**相关决策**：D-011

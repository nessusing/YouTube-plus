# F-21 发弹幕

**what**：模仿原生支持弹幕的平台，让用户在播放时写弹幕。弹幕作为一条公开的 YouTube 评论，用用户自己的账号发出去。评论弹幕（F-12）的二期。

**验收标准**
- F-21-AC1 播放时可以输入并发送弹幕，发出去的是用户自己账号的一条公开 YouTube 评论。
- F-21-AC2 发送时自动在开头加上当前播放时间（如「2:35 这里太绝了」），所以装了扩展的人会在 2:35 看到它（按 F-12-AC6 的规则）；没装的人看到的是普通评论，时间显示成可点的链接。
- F-21-AC3 发出后立刻在本地显示，不等 YouTube 回读。
- F-21-AC4 本地限速：默认每分钟最多 2 条，可调。

**风险**：发出去的是公开评论，用的是自己的账号；发得太频繁，YouTube 可能扣下审核、隐藏，严重的可能限制账号——所以要限速。

**开工时再定**（开工前 grilling）：输入框放在哪；全屏时怎么输入；发送失败怎么处理；要不要先预览再发。

# F-22 列表页缩略图同时动起来

**what**：首页、订阅、搜索、频道等列表页上，看得见的视频缩略图同时动起来，不用一个个悬停，方便挑视频。只是换图，没有声音，不是真的播放。

**验收标准**
- F-22-AC1 看得见的卡片同时动起来，不开播放器、没有声音。卡片有 YouTube 自带的 3 秒动图就循环播放它；没有就轮换 YouTube 自动截的前、中、后 3 张图，每张约 1 秒；两样都拿不到的保持静止。图下载好之前保持原来的缩略图，不闪空白。
- F-22-AC2 只处理看得见的卡片，滚出视野就换回静态图；标签页切到后台时停下。
- F-22-AC3 设置页里是一个单独的功能开关，默认关；开关即时生效，关掉后所有缩略图恢复原样。
- F-22-AC4 不碰 YouTube 自己的悬停预览；两者同时存在时以悬停预览为准：鼠标停在某张卡片上时那张卡片换回静态图，移开后继续动。
- F-22-AC5 生效范围：首页、订阅、搜索、频道、播放列表、历史记录、观看页右侧推荐里的横版视频卡片。Shorts 卡片、直播、首映和预告、播放列表 / 合辑卡片、观看页和迷你播放器的列表面板不动。滚动加载出来的和站内换页后的卡片同样生效。
- F-22-AC6 缩略图上原有的东西（时长、观看进度条、悬停按钮、TL;DR 图标）照常显示在动图上面，点缩略图的行为不变。

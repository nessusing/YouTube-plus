# F-12 评论弹幕

**what**：播放时把视频的评论显示在播放器上。带时间戳的评论在那个时刻出现；其余的用本地算法按热度撒到全片，或由 Gemini 读字幕放到相关时刻。参考 ComVi（CHI 2026，arXiv 2603.26173）。

**验收标准**

范围和开关
- F-12-AC1 全局开关默认关，关时什么都不跑。开了以后控件栏字幕按钮左边有一个弹幕开关，像字幕按钮一样记住，对所有视频生效。（§51.1）
- F-12-AC2 只在观看页显示（含小窗 F-08、影院、全屏）；迷你播放器、弹出窗口、广告时隐藏。嵌入、YouTube Music、Shorts、直播和直播回放不做（按钮变暗）；没有评论时按钮变暗并说明。（§51.1）
- F-12-AC3 只处理当前观看的视频，不提前生成；切视频时立刻停掉旧的（已发出的 Gemini 请求让它跑完、照样缓存），新视频只显示自己的评论。（§51.1）

评论
- F-12-AC4 直接调 YouTube 内部接口拉「热门」排序的前几百条一级评论，不滚页面、不碰评论区，不登录也能拉。不按语言筛，置顶和作者评论不加权。（§51.2）
- F-12-AC5 带链接、纯表情、太短、重复的评论不显示，也不送给 Gemini。热度综合赞数、回复数、新旧。（§51.3）

时间
- F-12-AC6 带时间戳的评论在那个时刻出现：每个时间戳出现一次；真目录（0:00 开头、5 个以上时间戳）只在 0:00 显示一次。同一时刻的几条（最多 3 条）有空行就同时显示，行不够的放进同一张卡轮播；它们比其他评论优先占行。所有行都占着时只往后推（最多 5 秒），不提前（免得剧透），推不进就放弃。（§51.4）
- F-12-AC7 设置里选定位方式「本地」（默认）或「AI」，切换后马上重排。（§51.5）
- F-12-AC8 本地：按热度从高到低放，最多放到「每分钟最多几条」（默认 0 = 能放多少放多少）。想放的时刻没有空行就挪到最近的空档，哪里都放不下就换下一条。按「最常重播」热度分配到各段、铺开全片；同一个视频、同样的设置每次排得一样；带「结尾」「反转」等词的只放最后 20 %（挪动后也一样）。（§51.5）
- F-12-AC9 AI：只信 Gemini 置信度 ≥ 0.9 的时间，时间撞车的放到另一行；其余的只用来填超过 20 秒、屏幕上一条都没有的空档；Gemini 回来前只显示带时间戳的。「每分钟最多几条」不影响 AI 模式。请求排在所有 TL;DR 前面，不受每小时 / 每天上限约束，但受熔断约束。整个视频用不了 AI（没字幕、没登录、额度、风控）时按设置退回「本地」或「只显示带时间戳的」，不弹提示。（§51.5）
- F-12-AC10 「行数」是同时显示的上限，字幕卡和飞过各设一个（默认 1 和 7）；评论少时不硬凑。字幕卡的显示时长按字数算，同一行前后两条之间留间隔。重排时只改还没开始的，已显示过的不重复。（§51.6）

显示
- F-12-AC11 三种风格，设置里单选、马上生效：字幕卡（默认）、飞过、侧栏。（§52）
- F-12-AC12 字幕卡：播放器顶部居中，仿官方字幕的胶囊底（多行的也是一整个胶囊），开头头像和 `@handle`（F-19），不显示赞数，链接和 @提及不能点。一行是一条评论，同时最多「行数」张卡，从上往下排：新卡放在最靠上、不挡住别的卡的位置，出现后不移动；播放器里放不下的那张不画。避开顶部标题栏和显示在上半部分的字幕；不能拖。（§51.7、§52.1）
- F-12-AC13 飞过：单行从右飞到左。「行数」是从顶部往下的车道数；同一车道里前一条完全进入画面（再加间隔）后下一条就能跟上，不重叠、不追尾，所以屏幕上的条数可以多于车道数。播放器放不下那么多车道时只用放得下的。挑评论的规则跟字幕卡一样，时间按车道排，可以跟字幕卡不同。（§52）
- F-12-AC14 侧栏：播放器右边的评论列表，像评论区：头像、赞数、嵌套回复，滚到底加载更多；只读；不过滤、不定位、不缓存。（§52）
- F-12-AC17 长评论：设置「超过几行算长」（默认 4，按参考行宽估算，头像和 `@handle` 算在内；0 = 不限）和超过后怎么办：不显示（默认）/ 截断加「…」/ 分屏滚动显示全文。两种风格共用，带时间戳的评论也算；字幕卡里的目录卡例外（总是滚动显示全文）。字幕卡每张最高就是这个行数，滚动时一屏这么多行；设 0 时两行一屏滚动。飞过是单行，选「分屏滚动」时按截断处理。

缓存、日志、设置
- F-12-AC15 按视频缓存 7 天（单独的容量上限，默认 3 MB，D-025），评论、标题、时长一起存；过期后重拉评论，Gemini 的判断保留。Gemini 的原始回答全部记进日志。自检只试拉评论，不试 Gemini。（§51.8）
- F-12-AC16 设置页「评论弹幕」标签：风格、定位方式、AI 用不了时的行为、调试、可编辑的提示词、七组参数（每组可恢复默认）。两个行数、长评论两项、每分钟最多几条放在预览旁边，不埋在参数组里。（§51.9、§52.4）
- F-12-AC18 预览用缓存里看过的视频的真实评论（可选视频，默认最近看的；没有缓存时用示例评论），按当前设置在假播放器上播放；改任何参数马上重算，不拉评论、不问 Gemini（AI 模式用缓存里已有的结果）。侧栏没有预览。
- F-12-AC19 预览显示结果：拉到 → 过滤后 → 排上多少条（因太长、没空位没排上的各多少），以及比上一次改动前多了或少了多少；整个视频一条时间轴，按行数分轨道，每条评论一个色块（按来源着色），背景是「最常重播」曲线，悬停看内容，点击后假播放器跳到那里。明细和时间轴固定在页面顶部，往下调参数时看得到。注明「拉多少评论」的改动要等缓存过期才对看过的视频生效。升级前缓存的视频没有标题和时长，重新打开一次才能选。

**不做**：分析画面；内置本地模型（D-005）。烧进画面里的字幕测不到、避不开。
**待定**：开发期放出来的参数哪些留给普通用户，以后再定。

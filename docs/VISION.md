# VISION

## 是什么
个人自用的 Chrome 扩展（MV3），一组 YouTube 工具：缩略图上的 TL;DR、能跨标签页和设备的队列、播放器增强、评论弹幕。

## 要解决的问题
开发动力来自我自己在 YouTube 网页版上遇到的各种痛点：

- 不点进去就能知道一个视频讲什么、标题是不是名副其实（TL;DR）。
- YouTube 自带的队列只在当前标签页里、关了就没；想要一个能跨标签页、跨设备、看完自动删的队列（队列）。
- 迷你播放器和观看页的播放器用起来不顺手：不能拖、没控件、滚下去就看不见（播放器）。
- 评论和视频是分开看的；想像弹幕网站那样边看边看到评论（评论弹幕）。

## 成功的定义
尽可能和 YouTube 官方的设计与使用习惯一致，**让用户察觉不到这些是非官方功能**，就是体验上最大的成功。这是整个项目的美学和取舍标准，「贴合官网」（D-003）是它的具体做法。

## 用户
只有我自己。但按能上架 Chrome 商店的标准写。

## 约束
- **零成本**：用浏览器里已登录的 Google 账号，不用 API key、不用 OAuth。（D-002）
- **贴合官网**：能从 YouTube 拿到的直接用，不另存、不让用户再设；界面和交互仿官网。（D-003）
- **每个功能单独开关、互相隔离**。
- **AI 只走 Gemini 网页版**，不内置本地模型，不分析画面，扩展保持轻量。（D-004、D-005）
- 技术栈：WXT + TypeScript + 原生 DOM / Shadow DOM。（D-001）
- 图标沿用现在这个（红色播放键取自 YouTube 商标，用户确认不换，D-033）。

## 非目标
- Shorts、直播中、预告和首映（TL;DR、评论弹幕都不做）；嵌入播放器、YouTube Music。
- 自己抓字幕、读不到字幕时的降级总结（暂不做，见 TASKS 的 F-14）。

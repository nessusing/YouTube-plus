# F-06 清理列表

**what**：在官方 ⋮ 菜单里一键「清空全部」「移除已看完」；在列表面板里把一条拖出去就删掉。

**验收标准**
- F-06-AC1 「清空全部」「移除已看完」加在官方 ⋮ 菜单最下面：列表页上（能编辑的列表，两种队列模式都有）；观看页和迷你播放器的列表面板上（只在接管、且面板是选中的列表时）。找不到官方 ⋮ 就没有入口，不自己补按钮。（§47）
- F-06-AC2 点了直接删，不确认、不能撤销。「已看完」= 观看进度 ≥ 90 %；一个都没有时提示（⚠️ 未确认：取自 e2e 测试）。（§47）
- F-06-AC3 正在播的视频被删（这里或 AC4）时照常播完，再接着播原来排在它后面、还留在列表里的；没有就交给 YouTube 的自动播放。（§47）
- F-06-AC4 观看页、迷你播放器的列表面板里，把一条拖到面板外松开就删掉；拖出面板时那一行变红显示「松开即删除」；在面板内松开是普通的重新排序（⚠️ 未确认：取自 e2e 测试）。只在接管且面板是选中的列表时有效；列表页没有。（§48）
- F-06-AC5 拖出删除不弹提示、不能撤销；删除失败时那一行回到原位并提示。（§48）

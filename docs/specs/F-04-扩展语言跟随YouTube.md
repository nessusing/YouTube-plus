# F-04 扩展语言跟随 YouTube

**what**：扩展所有界面（设置页、缩略图上的提示、日志等）的语言跟 YouTube 的界面语言走，扩展里没有语言选项。

**验收标准**
- F-04-AC1 YouTube 界面语言是 `zh*`（含繁体）时扩展用中文，其他一律用 English。（§3，P23）
- F-04-AC2 设置页没有语言选项。（§3，P23）
- F-04-AC3 没打开过 YouTube 时（例如刚装完就打开设置页）按浏览器语言；打开 YouTube 后自动改成 YouTube 的语言。（§3，P23）
- F-04-AC4 用户在 YouTube 上改了界面语言后，扩展各处跟着切换。（P23）

**代价**：「YouTube 用英文、扩展用中文」这种组合做不到，不留手动覆盖。

**相关**：TL;DR 的要点语言跟视频走，见 F-03-AC4（同在 P23 里改的）。

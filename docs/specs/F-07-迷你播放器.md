# F-07 迷你播放器

**what**：给 YouTube 右下角的迷你播放器加上控件栏、拖动、最小化。播放器的各个子开关都在「设置 → 播放器」，除循环按钮（F-10）外默认开。

**验收标准**
- F-07-AC1 鼠标悬停时显示官方控件栏（音量、进度条、时间、齿轮）；不补「上一个 / 下一个」（YouTube 2026-11 改版自己去掉的）。（§35.1）
- F-07-AC2 只能从视频画面区域开始拖；松手时离边近就吸到边上，在角落就吸到角上，否则停在原地；拖动时视频继续播。（§35.2）
- F-07-AC3 位置和大小在所有标签页共用，下次打开页面还在；设置页可以重置。（§35.3）
- F-07-AC4 ✕ 左边有一个最小化按钮，点了缩成左下角只显示标题的横条，视频继续播；点横条还原。（§44）
- F-07-AC5 最小化状态会记住（刷新后、所有标签页）；最小化只是藏起来、没关，队列和拖动不受影响。（§44）

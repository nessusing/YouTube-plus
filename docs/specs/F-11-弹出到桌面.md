# F-11 迷你播放器弹出到桌面

**what**：把播放器搬进一个置顶的桌面小窗口（Document Picture-in-Picture），切到别的程序也能看。窗口里只有画面和控件；列表是二期（F-18）。

**验收标准**
- F-11-AC1 浏览器支持 Document PiP（Chrome / Edge 116+）时可用；不支持时设置项变灰，自检显示「注意」。（§50）
- F-11-AC2 打开方式：迷你播放器「展开」按钮右边的按钮，或快捷键（默认 Shift+I，可改；跟 YouTube 自己的快捷键冲突时不让保存）。在观看页按快捷键会先缩成迷你播放器再弹出。切走标签页时不自动弹出。（§50）
- F-11-AC3 弹出期间主页面的迷你播放器藏起来，左下角横条显示「在弹出窗口里播放」；在主页面点别的视频、列表放下一条，都在弹出窗口里接着播；弹出窗口里有完整的控件栏和常用按键。（§50）
- F-11-AC4 收回：快捷键、点横条、窗口的 ✕；主页面去观看页、后退到正在播的视频、按 Esc 关迷你播放器时也会收回。（§50）
- F-11-AC5 全屏：弹出窗口里不允许全屏，所以按全屏 = 收回 → 浏览器窗口全屏 → 播放器盖满整页；退出全屏后回到弹出窗口。（§50）

**改不了的限制**：窗口标题栏是 Chrome 画的；只能由用户操作打开；同时只能有一个；Wayland 下可能不置顶（没测）。
